# ASRA Wedding Canvas — Backend API

Express.js backend service powering the ASRA Wedding Canvas platform.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Configure environment
cp .env.example .env

# 3. Start development server
npm run dev
```

## API Endpoints

- `GET /api/health` — Service health check
- `GET /api/products` — Product catalog endpoint placeholder
